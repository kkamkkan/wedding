RSVP 관리자 로그인

하객의 참석 여부와 손님 명단은 개인정보가 포함되어 있어 관리자 Google 계정으로 로그인한 뒤에만 표시됩니다.

관리자 권한 설정이 한 번 필요합니다

Google 로그인은 성공했지만 Firestore에서 RSVP를 읽을 권한이 없습니다. 아래 UID를 Firebase의 wedding_admins 컬렉션에 문서 ID로 등록한 뒤, 하단의 보안 규칙을 적용하면 이 계정만 관리자 화면을 볼 수 있습니다.

-

Firestore → 데이터 → 컬렉션 시작 → wedding_admins → 문서 ID에 위 UID 입력 → 임의 필드 하나(예: role = admin) 저장
